Developed a Lexical Analyzer in C as part of a compiler design project to scan and tokenize source code written in a subset of the C programming language. The analyzer reads the input program character by character and breaks it down into meaningful tokens such as keywords (int, while), identifiers, constants, operators (+, -, ==), separators (;, {, }), and ignores comments (//, /*...*/). Implemented finite state machine logic to identify token patterns, classify them accurately, and report lexical errors for invalid inputs. The program also tracks line numbers and outputs the tokens in a structured format to aid in debugging and further stages of compilation. File handling, string processing, and conditional parsing techniques were used to manage real-time input analysis. This project enhanced my understanding of compiler front-end design, tokenization strategies, and low-level programming concepts in C, forming a strong foundation for building full compiler pipelines and language processing tools.
